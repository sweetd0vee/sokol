# Сокол — фронтенд

Веб-интерфейс для внутреннего продукта «Сокол»: панель с разделами рекомендаций, проверок, аналитики, настроек и инструментов, а также профиля пользователя.

## Порты (локальная разработка)

| Сервис | URL |
|--------|-----|
| UI (Vite) | http://localhost:5180 |
| API (бэкенд) | http://localhost:8800 |

Порты задаются в `.env.development` в корне фронтенда. Прокси Vite перенаправляет `/api` → `http://127.0.0.1:8800`.

## Возможности

- Авторизация (локальная заглушка; готово к замене на Keycloak).
- Разделы: Проверки, Рекомендации, Аналитика, Канцлер, Настройки, Инструменты (генерация раздела II АЗ и ДЗ).
- Профиль пользователя с аватаром.
- Экспорт таблиц проверок и рекомендаций в XLSX, DOCX и PDF прямо из соответствующих вкладок.

## Стек

- React 19 + TypeScript
- Vite 7
- TanStack Query, Axios
- Tailwind CSS

## Быстрый старт

**1. Запустите бэкенд** (в отдельном терминале, см. `sokol-backend/README.md`):

```powershell
cd sokol-backend
.\run_dev.ps1
```

**2. Запустите фронтенд:**

```bash
cd sokol-frontend
npm install
npm run dev
```

**3. Откройте в браузере:** http://localhost:5180

## Скрипты

- `npm run dev` — локальная разработка (порт **5180**)
- `npm run build` — сборка
- `npm run preview` — предпросмотр сборки
- `npm run lint` — линтинг

## Переменные окружения

Файл `.env.development` (уже в репозитории):

```bash
VITE_DEV_SERVER_PORT=5180
VITE_DEV_API_PORT=8800
```

Дополнительно в `.env.local` (опционально):

- `VITE_API_URL` — базовый URL API. В dev обычно **не нужен**: запросы идут через прокси Vite на тот же origin (`5180`), а `/api` проксируется на бэкенд **8800**.

## Структура проекта

- `src/api` — HTTP‑клиент и запросы
- `src/components` — страницы и UI‑компоненты
- `src/contexts` — контексты (например, состояние авторизации)
- `src/hooks` — переиспользуемые React hooks
- `src/utils` — общие утилиты дат, экспорта, скачивания файлов и проверки `.docx`

## Актуальные маршруты

- `/checks` — проверки
- `/recommendations` — рекомендации
- `/analytics` — аналитика
- `/tools` — инструменты генерации документов
- `/kantsler` — раздел «Канцлер»
- `/settings` — справочники
- `/profile` — профиль

Отдельной вкладки `/export` нет: экспорт встроен в таблицы `Проверки` и `Рекомендации`.

## Частые проблемы

**Ошибка 500 при генерации раздела II** — чаще всего бэкенд не запущен или слушает другой порт. Проверьте http://localhost:8800/docs

**Порт UI занят** — измените `VITE_DEV_SERVER_PORT` в `.env.development` и `SOKOL_CORS_ORIGINS` в `sokol-backend/.secrets/sokol.env`.
