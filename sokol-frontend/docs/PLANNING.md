# Планирование

Раздел `/planning` — `GET /api/v1/analytics/planning`. UI: `PlanningAnalyticsDashboard`.

## Фильтры

Год / квартал, департаменты (`audit_object`). В UI нет среза «месяц» и фильтра аудиторов.

Query: `granularity`, `years`, `quarters`, `months` (всегда пустой из UI), `departments`.

Bootstrap: `granularity=year`, затем перезапрос при смене фильтров.

Период для охвата и нерешённых рекомендаций — дата начала проверки. Список неохваченных департаментов пересчитывается при смене года/квартала.

## Дашборды

1. **Итого планирования** — KPI: **Охват департаментов** (%), **С проверками**, **Не охвачено** (число / всего), **Красные рекомендации**.
2. **Неохваченные департаменты** — нумерованный список подразделений, у которых за выбранный период не было рекомендаций с этим департаментом в объекте аудита. Фильтр департаментов на охват **не влияет**. Плейсхолдер «Не указан» в список не входит.
3. **Рекомендации со статусом «Не решено»** — горизонтальные столбцы по департаментам с ненулевым числом нерешённых рекомендаций, по убыванию. При наведении — ключи проверок, в которых был такой статус.
4. **Рекомендации высокой существенности по департаментам** — рейтинг по высокой существенности (уточняется отдельно).

## Экспорт

Visual export **включён** (html / pdf / docx / xlsx), как на вкладках аналитики. В конструктор: галочка на карточке (**«В конструктор»**) → **«Добавить в конструктор (N)»**. Снимки попадают на текущий дашборд в `/constructor` — [CONSTRUCTOR.md](CONSTRUCTOR.md).
