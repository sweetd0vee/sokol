# Планирование

Раздел `/planning` — `GET /api/v1/analytics/planning`.

## Фильтры

Год / квартал / месяц, департаменты (`audit_object`).

Query: `granularity`, `years`, `quarters`, `months`, `departments`.

## Дашборды

1. **Охват департаментов** — число проверок по подразделениям за период (фильтр департаментов на охват не влияет).
2. **Аналитика департаментов** — топ по проверкам и рекомендациям.
3. **Красные рекомендации** — рейтинг по высокой существенности.

KPI: % охвата, охваченные/неохваченные, сумма красных рекомендаций.

## Экспорт

Отключён (`canExport={false}`). Включить — по аналогии с analytics visual export.
