# Планирование

Раздел `/planning` — `GET /api/v1/analytics/planning`. UI: `PlanningAnalyticsDashboard`.

## Фильтры

Год / квартал, департаменты (`audit_object`). В UI нет среза «месяц» и фильтра аудиторов.

Query: `granularity`, `years`, `quarters`, `months` (всегда пустой из UI), `departments`.

Bootstrap: `granularity=year`, затем перезапрос при смене фильтров.

## Дашборды

1. **Итого планирования** — KPI: **Охват департаментов** (%), **С проверками** (охват / всего), **Не охвачено** (%), **Красные рекомендации** (сумма высокой существенности).
2. **Неохваченные департаменты** — нумерованный список **неохваченных** подразделений за период (не график числа проверок). Фильтр департаментов на охват **не влияет** (backend считает coverage по всем департаментам справочника). В каталоге экспорта секция может называться «Охват департаментов».
3. **Проверки и рекомендации по департаментам** — горизонтальные столбцы: проверки и рекомендации по подразделениям.
4. **Рекомендации высокой существенности по департаментам** — рейтинг по высокой существенности.

## Экспорт

Visual export **включён** (html / pdf / docx / xlsx), как на вкладках аналитики. В конструктор: галочка на карточке (**«В конструктор»**) → **«Добавить в конструктор (N)»**. Снимки попадают на текущий дашборд в `/constructor` — [CONSTRUCTOR.md](CONSTRUCTOR.md).
