# Планирование

Раздел `/planning` — витрина для планирования аудиторского охвата. Данные те же, что в аналитике (`checks` / `recommendations` из `SokolDataContext`); агрегации на клиенте.

## Фильтры

- Год / квартал / месяц
- Департаменты (объекты аудита)

## Дашборды

1. **Охват департаментов** — доля известных подразделений, по которым в выбранном периоде есть хотя бы одна проверка (через связанные рекомендации). Показывает «дыры» в плане охвата.
2. **Аналитика департаментов** — топ подразделений по проверкам и рекомендациям за период. Помогает сравнить нагрузку и «хвост» корректирующих действий.
3. **Красные рекомендации по департаментам** — рейтинг подразделений по рекомендациям высокой существенности. Приоритет для планирования повторных / углублённых проверок.

Сводка KPI сверху: % охвата, число охваченных / без охвата, суммарно красных рекомендаций.

## Возможные следующие дашборды

- Динамика охвата по кварталам
- Департаменты без проверок N лет подряд
- Соотношение плановых / внеплановых по департаментам
