# Планирование

Раздел `/planning` — витрина для планирования аудиторского охвата.

Данные: backend `GET /api/v1/analytics/planning` (агрегация по всей БД).

## Фильтры

- Год / квартал / месяц
- Департаменты (объекты аудита)

Query-параметры: `granularity`, `years`, `quarters`, `months`, `departments`.

## Дашборды

1. **Охват департаментов** — доля известных подразделений, по которым в выбранном периоде есть хотя бы одна проверка (через связанные рекомендации). Считается **только по периоду** (фильтр департаментов на охват не влияет).
2. **Аналитика департаментов** — топ подразделений по проверкам и рекомендациям за период (с учётом фильтра департаментов).
3. **Красные рекомендации по департаментам** — рейтинг по рекомендациям высокой существенности.

Сводка KPI: % охвата, число охваченных, % неохваченных, сумма красных рекомендаций.

## Экспорт

Кнопки экспорта в сайдбаре **пока отключены** (`canExport={false}`). Включить — по аналогии с analytics visual export.

## Возможные следующие дашборды

- Динамика охвата по кварталам
- Департаменты без проверок N лет подряд
- Соотношение плановых / внеплановых по департаментам
