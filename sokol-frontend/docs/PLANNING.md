# Планирование

Раздел `/planning` — `GET /api/v1/analytics/planning`. UI: `PlanningAnalyticsDashboard`.

## Фильтры

Год / квартал, департаменты (`audit_object`). В UI нет среза «месяц» и фильтра аудиторов.

Query: `granularity`, `years`, `quarters`, `months` (всегда пустой из UI), `departments`.

Bootstrap: `granularity=year`, затем перезапрос при смене фильтров.

## Дашборды

1. **Сводка планирования** — KPI: % охвата, «С проверками» (охват / всего), % неохваченных, сумма красных рекомендаций.
2. **Охват департаментов** — нумерованный список **неохваченных** подразделений за период (не график числа проверок). Фильтр департаментов на охват **не влияет** (backend считает coverage по всем департаментам справочника).
3. **Аналитика департаментов** — горизонтальные столбцы: проверки и рекомендации по подразделениям.
4. **Красные рекомендации по департаментам** — рейтинг по высокой существенности.

## Экспорт

Visual export включён (html / pdf / docx / xlsx), как на вкладках аналитики. В конструктор: галочка на карточке → **В конструктор**. Снимки попадают на текущий дашборд в `/constructor` — [CONSTRUCTOR.md](CONSTRUCTOR.md).
