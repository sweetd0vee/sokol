# UI-стандарты SOKOL Frontend

Актуальные размеры окон/блоков и палитра цветов, зафиксированные в коде (июль 2026).  
Источник токенов: `src/constants/formLayout.ts`, `tailwind.config.js`, `src/index.css`, layout-компоненты.

База Tailwind: **1rem = 16px** (если не переопределён `html` font-size).

## 2. Формы редактирования (проверки / рекомендации)

Токены: `src/constants/formLayout.ts`, сетка: `src/index.css`.

| Токен / правило | Значение | px |
|-----------------|----------|-----|
| Ширина страницы формы | `max-w-7xl` (`FORM_PAGE_CLASS`) | макс. **1280px** |
| Вертикальный ритм секций | `space-y-3` | **12px** |
| Padding секции | `p-3` | **12px** |
| Скругление секции | `rounded-lg` | **8px** |
| Gap внутри секции | `gap-3` (`FORM_GRID_GAP`) | **12px** |
| Row-gap полей (mobile/desktop) | `0.75rem` | **12px** |
| Column-gap полей (≥768px) | `2.75rem` | **44px** |
| Высота равных контролов | `.form-equal-control` → `2.5rem` | **40px** |
| Min-height textarea | `min-h-[3.5rem]` | **56px** |
| Input vertical padding | `py-1.5` | **6px** сверху/снизу |
| Заголовок секции | `text-lg` | **18px** |
| Подпись поля | `text-sm` | **14px** |
| Breakpoint сетки 3/4 колонок | `min-width: 768px` | **768px** |

### Ширина полей в ряду

На desktop (`≥768px`):

- **4 колонки** (`.form-row-4`): равные доли `1fr`, промежутки **44px**.
- **3 колонки** (`.form-row-3`): каждое поле = ширина одной колонки из 4-колоночного ряда:  
  `calc((100% - 8.25rem) / 4)` → `8.25rem = 132px` (три промежутка по 44px).  
  Свободное место справа остаётся пустым (или занимает `.form-field-wide`).

### Состояния секций

| Состояние | Фон | Рамка |
|-----------|-----|-------|
| Незаполненная | `bg-gray-50` → **#F9FAFB** | `#B8BEC8` |
| Все поля заполнены | `rgb(255, 248, 230)` → **#FFF8E6** | `#B8BEC8` |

Служебные поля ключа: `border-2 border-gray-400` + `bg-green-100` (**#DCFCE7**).

Ошибка обязательного поля: рамка `#E59A9A`, focus `#D9534F`, кольцо `#F3C5C5`.

## 6. Статусы и индикаторы (бейджи / кружки)

Tailwind-классы → приблизительные HEX палитры Tailwind 3:

### Проверки (статус в таблице)

| Статус | Класс | Фон (ориентир) |
|--------|-------|----------------|
| Завершено | `bg-green-100` | `#DCFCE7` |
| В процессе | `bg-yellow-100` | `#FEF9C3` |
| Не начато / прочее | `bg-gray-200` | `#E5E7EB` |

### Рекомендации — статус

| Статус | Класс | Фон |
|--------|-------|-----|
| Исполнено | `bg-green-100` | `#DCFCE7` |
| Не решено | `bg-red-100` | `#FEE2E2` |
| На контроле | `bg-gray-200` | `#E5E7EB` |
| В процессе | `bg-yellow-100` | `#FEF9C3` |

### Рекомендации — дополнительный статус

| Статус | Класс | Фон |
|--------|-------|-----|
| В срок | `bg-green-100` | `#DCFCE7` |
| Срок нарушен | `bg-red-100` | `#FEE2E2` |
| На контроле | `bg-gray-200` | `#E5E7EB` |

### Уровень существенности (кружки)

Те же пастельные тона, что у бейджей статусов:

| Уровень | Класс | HEX (ориентир) |
|---------|-------|----------------|
| Низкий | `bg-green-100` | `#DCFCE7` |
| Средний | `bg-yellow-100` | `#FEF9C3` |
| Высокий | `bg-red-100` | `#FEE2E2` |

### Индикатор рекомендации (кружки / иконки)

Кружки — пастель как у статусов; иконки в таблице — те же оттенки с opacity `/45`:

| Значение | Кружок | Иконка |
|----------|--------|--------|
| Не указан | прозрачный + `border-gray-300` | — |
| В процессе | `bg-yellow-100` | `text-yellow-500/45` |
| Ожидает | `bg-gray-200` | `text-gray-500/45` |
| Не решено | `bg-red-100` | `text-red-500/45` |
| Исполнено | `bg-green-100` | `text-green-500/45` |

Текст на бейджах обычно `text-gray-800` (**#1F2937**).
