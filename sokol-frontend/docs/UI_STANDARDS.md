# UI-стандарты SOKOL Frontend

Актуальные размеры окон/блоков и палитра цветов, зафиксированные в коде (август 2026).  
Источник токенов: `src/constants/formLayout.ts`, `tailwind.config.js`, `src/index.css`, layout-компоненты.

База Tailwind: **1rem = 16px** (если не переопределён `html` font-size).

## 2. Формы редактирования (проверки / рекомендации / профиль)

Токены: `src/constants/formLayout.ts`, сетка: `src/index.css`.

| Токен / правило | Значение | px |
|-----------------|----------|-----|
| Ширина страницы формы | `FORM_PAGE_CLASS` → `max-w-7xl` | макс. **1280px** |
| Вертикальный ритм между секциями | `FORM_STACK_CLASS` → `space-y-8` | **32px** |
| Gap внутри секции | `space-y-5` / `FORM_SECTION_INNER_STACK_CLASS` | **20px** |
| Padding секции | `p-5` | **20px** |
| Скругление секции | `rounded-lg` | **8px** |
| Рамка секции | `border-[#b8bec8]` | **#B8BEC8** |
| Фон секции | `bg-white` | **#FFFFFF** (серый фон секций не используется) |
| Row-gap полей | `1.25rem` (`.form-row-*`) | **20px** |
| Column-gap полей (≥768px) | `2.75rem` | **44px** |
| Высота равных контролов | `.form-equal-control` → `2.5rem` | **40px** |
| Min-height textarea (формы) | `FORM_TEXTAREA_CLASS` → `min-h-[6.5rem]` | **104px** |
| Input vertical padding | `py-1.5` | **6px** сверху/снизу |
| Фокус поля | `focus:border-gray-400` + ring `gray-300/40` | приглушённый, без синей обводки |
| Заголовок секции | `text-lg` | **18px** |
| Подпись поля | `text-sm` + `leading-relaxed` | **14px** |
| Breakpoint сетки 3/4 колонок | `min-width: 768px` | **768px** |

### Ширина полей в ряду

На desktop (`≥768px`):

- **4 колонки** (`.form-row-4`): равные доли `1fr`, промежутки **44px**.
- **3 колонки** (`.form-row-3`): каждое поле = ширина одной колонки из 4-колоночного ряда:  
  `calc((100% - 8.25rem) / 4)` → `8.25rem = 132px` (три промежутка по 44px).  
  Свободное место справа остаётся пустым (или занимает `.form-field-wide`).

### Служебные поля и ошибки

| Элемент | Стиль |
|---------|--------|
| Ключ (readonly) | `FORM_SERVICE_INPUT_CLASS` → обычная рамка + `bg-green-100` (**#DCFCE7**) |
| Ошибка обязательного поля | `FORM_FIELD_ERROR_CLASS` → рамка `#E59A9A`, focus `#D9534F`, кольцо `#F3C5C5` |
| Outline-кнопка (Назад / Добавить / Удалить) | `FORM_OUTLINE_BUTTON_CLASS` → рамка/текст `#6699FF`, hover `#3B82F6` |
| Сохранить | `FORM_SAVE_BUTTON_CLASS` → `#90EE90` |

Карточки «Управление вложениями»: рамка `#B8BEC8`, текст ссылки `#6699FF`; между карточкой и полями номера/даты — `gap-6`.

### Контрольная зона (рекомендация)

Порядок блоков:

1. **Срок исполнения** — дата + вложение слева, комментарий справа.
2. **Снять с контроля** — та же раскладка; вместо «Добавить» — вложение.
3. **Перенос срока** — строки дата/комментарий + кнопка «Добавить»; «Удалить» в стиле outline с голубой корзиной.

Поля **Статус** / **Дополнительный статус** на форме подсвечиваются фоном как бейджи в таблице (inline `backgroundColor`, см. §6).

## 6. Статусы и индикаторы (бейджи / кружки)

### Проверки (статус в таблице)

| Статус | Класс | Фон |
|--------|-------|-----|
| Завершено | `bg-green-100` | `#DCFCE7` |
| В процессе | `bg-yellow-100` | `#FEF9C3` |
| Не начато / прочее | `bg-gray-200` | `#E5E7EB` |

### Рекомендации — статус (таблица и поля формы)

| Статус | Класс / фон формы | HEX |
|--------|-------------------|-----|
| Исполнено | `bg-green-100` | `#DCFCE7` |
| Не решено | `bg-red-100` | `#FEE2E2` |
| На контроле | `bg-gray-200` | `#E5E7EB` |
| В процессе | `bg-yellow-100` | `#FEF9C3` |

### Рекомендации — дополнительный статус

| Статус | Класс / фон формы | HEX |
|--------|-------------------|-----|
| В срок | `bg-green-100` | `#DCFCE7` |
| Срок нарушен | `bg-red-100` | `#FEE2E2` |
| На контроле | `bg-gray-200` | `#E5E7EB` |

На форме цвета задаются через `getRecommendationStatusFieldStyle` / `getRecommendationAdditionalStatusFieldStyle` (inline `backgroundColor`), чтобы нативный `<select>` стабильно подсвечивался.

### Уровень существенности (кружки)

| Уровень | Класс / hex в коде |
|---------|--------------------|
| Низкий | `bg-[#A9D18E]` |
| Средний | `bg-[#FBEB8D]` |
| Высокий | `bg-[#FF4347]` |

### Индикатор рекомендации

| Значение | Кружок (`dotClassName`) | Иконка в таблице/форме |
|----------|-------------------------|-------------------------|
| Не указан | прозрачный + `border-gray-300` | — |
| В процессе | `#FBEB8D` | `text-yellow-500` |
| Ожидает | `bg-gray-200` | `text-gray-500` |
| Не решено | `#FF4347` | `text-red-500` |
| Исполнено | `#A9D18E` | `text-green-500` |

Текст на бейджах обычно `text-gray-800` (**#1F2937**).
