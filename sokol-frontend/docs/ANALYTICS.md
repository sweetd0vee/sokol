# Аналитика

Раздел `/analytics` — аналитическая витрина SOKOL. Агрегации считаются на backend по всей БД (без лимитов list API).

## API

| Вкладка | Endpoint |
|---|---|
| Проверки | `GET /api/v1/analytics/checks` |
| Рекомендации | `GET /api/v1/analytics/recommendations` |
| Мониторинг | `GET /api/v1/analytics/monitoring` |
| ДВА | `GET /api/v1/analytics/dva` |

Планирование (отдельный раздел `/planning`): `GET /api/v1/analytics/planning` — см. [PLANNING.md](PLANNING.md).

Общие query-параметры (повторяемые списки): `granularity`, `years`, `quarters`, `months`, `auditors`, `departments`.  
Для рекомендаций/мониторинга дополнительно: `statuses`, `additionalStatuses`, `materialityLevels`.

Ответ — готовые KPI/серии + `filterOptions` (аудиторы, департаменты, `anchorDates`). Поля в camelCase. Требуется Bearer JWT.

## Общая логика UI

- Вкладки: «Проверки», «Рекомендации», «Мониторинг», «ДВА».
- Фильтры в боковой панели; при смене фильтров фронт перезапрашивает соответствующий endpoint.
- Периодичность графиков = выбранный срез (год/квартал/месяц).
- Экспорт — визуальный снимок карточек с экрана; метаданные берутся из ответа API.

## Вкладка «Проверки»

Период по `start_date` проверки. Департаменты — через связанные рекомендации (`audit_object`).

Карточки: Сводка KPI, Количество проверок, Виды, Типы, Карта департаментов, Оценка эффективности.

## Вкладка «Рекомендации»

Период по `deadline`. Карточки: Сводка KPI, Количество рекомендаций, Статусы/Существенность по периодам, Существенность, Индикаторы, Карта департаментов, Матрица существенности.

## Вкладка «Мониторинг»

Тот же фильтр/источник, что рекомендации; узкий срез по исполнению сроков. Карточки: Сводка KPI, Динамика сроков, Статусы, Срок исполнения.

## Вкладка «ДВА»

Объединяет проверки (`start_date`) и рекомендации (`deadline`). Карточки: Сводка KPI, Портфель, Нагрузка аудиторов (проверки / рекомендации — столбчатые диаграммы), Документы и закрытие, Tree Map аудиторов (проверки / рекомендации).

## Ограничения

- Drill-down API и сохранённые серверные отчёты не реализованы.
- Наблюдения пока не участвуют в аналитике.
