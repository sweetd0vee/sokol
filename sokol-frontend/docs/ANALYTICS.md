# Аналитика

Раздел `/analytics` — клиентская аналитическая витрина SOKOL. Она строится на уже загруженных в `SokolDataContext` проверках и рекомендациях: `checks` загружаются с лимитом 500, `recommendations` — с лимитом 1000. Отдельного backend analytics API сейчас нет, все агрегации выполняются в браузере.

## Общая логика

- Вкладки: «Проверки», «Рекомендации», «Мониторинг», «ДВА».
- Общие фильтры: год, квартал, месяц, аудитор, департамент / объект аудита.
- Дополнительные фильтры рекомендаций: существенность, основной статус, дополнительный статус.
- Периодичность выбирается автоматически: если выбран месяц — месячный срез, если квартал — квартальный, иначе годовой.
- Карточки дашборда можно переставлять; layout хранится в `localStorage` по ключам `sokol.analytics.layout.*`.
- Экспорт выбираемых секций доступен из боковой панели. Для проверок и рекомендаций используются специализированные экспортеры, для «Мониторинга» и «ДВА» — generic analytics export.

## Вкладка «Проверки»

Цель: показать состояние аудиторского портфеля по проверкам: сколько работ запланировано, идет сейчас, завершено, как они распределены по срокам, видам, типам, аудиторам и документам.

Реализованные карточки:

- «Сводка KPI» — общий портфель проверок, количество запланированных, текущих и завершенных проверок, доля завершенных. Бизнес-смысл: быстрый health-check выполнения плана аудита.
- «Динамика и накопительный итог» — проверки по периоду и накопленный портфель. Бизнес-смысл: видно, растет ли нагрузка и в какие периоды концентрируются проверки.
- «Структура по видам» — распределение по видам проверок (`ИТ`, `бизнес`, `риски`, `корпоуправление`, `иные`). Бизнес-смысл: помогает понять фокус аудиторской активности.
- «Структура по типам проверок» — плановые, внеплановые и тематические проверки. Бизнес-смысл: показывает баланс плановой работы и реактивных / тематических инициатив.
- «Статусы по сроку» — статусы проверок по месяцам, кварталам или годам. Бизнес-смысл: позволяет видеть, где накапливаются незавершенные работы.
- «Готовность документов» — заполненность реквизитов приказа, программы, АЗ и ДЗ. Бизнес-смысл: контроль документальной готовности проверки, особенно перед закрытием.
- «Tree Map аудиторов» — нагрузка руководителей проверок по площади блока. Бизнес-смысл: визуально подсвечивает перекосы загрузки между аудиторами.

## Вкладка «Рекомендации»

Цель: управлять портфелем рекомендаций как набором обязательств: сроки, исполнение, существенность, ответственные аудиторы, объекты аудита и связь с проверками.

Реализованные карточки:

- «Сводка KPI» — всего рекомендаций, исполнено, не решено, высокосущественные, процент исполнения и процент нарушения срока. Бизнес-смысл: управленческая оценка риска и дисциплины исполнения.
- «Динамика сроков» — рекомендации по срокам исполнения. Бизнес-смысл: показывает будущую нагрузку на контроль и пики дедлайнов.
- «Количество рекомендаций» — динамика за выбранный период (год/квартал/месяц) и накопительный итог. Бизнес-смысл: сколько рекомендаций появляется по периодам и как растёт общий объём.
- «Статусы по периодам» — распределение статусов внутри каждого периода. Бизнес-смысл: помогает выявлять периоды, где много нерешенных или зависших рекомендаций.
- «Существенность по периодам» — распределение уровней существенности внутри каждого периода. Бизнес-смысл: фокусирует внимание на периодах с высокой концентрацией значимых рисков.
- «Существенность» — распределение уровней существенности за период. Бизнес-смысл: общий риск-профиль портфеля.
- «Статусы» — распределение по основным статусам. Бизнес-смысл: контроль стадий жизненного цикла рекомендаций.
- «Срок исполнения» — распределение по дополнительным статусам (`в срок`, `срок нарушен`, `на контроле`). Бизнес-смысл: отдельный контроль дисциплины дедлайнов.
- «Индикаторы» — распределение по визуальным индикаторам таблицы рекомендаций. Бизнес-смысл: быстрый «светофор» состояния портфеля.
- «Объекты аудита» — департаменты / объекты аудита по количеству рекомендаций. Бизнес-смысл: выявляет подразделения с максимальной концентрацией замечаний.
- «Нагрузка аудиторов» — топ аудиторов по рекомендациям. Бизнес-смысл: контроль загрузки контролирующих сотрудников.
- «По проверкам» — количество рекомендаций на ключ проверки. Бизнес-смысл: помогает найти проверки с большим хвостом корректирующих действий.

## Вкладка «Мониторинг»

Цель: оперативный контроль исполнения рекомендаций и сроков. Это более узкий управленческий срез по рекомендациям, сфокусированный на просрочке, статусах контроля и проблемных объектах.

Реализованные карточки:

- «Сводка KPI» — на контроле, срок нарушен, исполнено, в работе, процент просрочки. Бизнес-смысл: быстрый статус мониторинга исполнения.
- «Динамика сроков исполнения» — статусы рекомендаций по периодам. Бизнес-смысл: показывает, когда и в каком статусе находятся контрольные обязательства.
- «Просрочка по департаментам» — объекты аудита с наибольшим объемом рекомендаций. Бизнес-смысл: помогает определить, куда направить управленческое внимание.
- «Горизонт сроков» — ближайшие сроки и долгий хвост. Бизнес-смысл: планирование контрольных мероприятий и напоминаний.
- «Воронка исполнения» — от общего портфеля к закрытию. Бизнес-смысл: оценка эффективности процесса доведения рекомендаций до результата.
- «Tree Map проблемных объектов» — просроченные и высокосущественные рекомендации по объектам аудита. Бизнес-смысл: карта зон риска.

## Вкладка «ДВА»

Цель: сводная управленческая аналитика для Департамента внутреннего аудита. Она объединяет проверки и рекомендации, чтобы видеть портфель работ, нагрузку команды, документы и закрытие рекомендаций в одном месте.

Реализованные карточки:

- «Сводка KPI» — проверки, рекомендации, аудиторы, объекты аудита, завершенность проверок, исполнение рекомендаций. Бизнес-смысл: единый executive summary по портфелю ДВА.
- «Портфель проверок и рекомендаций» — проверки и рекомендации по периодам на одном графике. Бизнес-смысл: сопоставление аудиторской активности и последующего хвоста рекомендаций.
- «Нагрузка аудиторов» — суммарная нагрузка по проверкам и рекомендациям. Бизнес-смысл: помогает балансировать работу команды.
- «Карта департаментов» — объекты аудита по объему рекомендаций. Бизнес-смысл: показывает, где концентрируются результаты аудита.
- «Риск-профиль рекомендаций» — распределение рекомендаций по существенности. Бизнес-смысл: оценка качественного риска портфеля, а не только количества.
- «Матрица аудитор × срок» — тепловая таблица нагрузки по аудиторам и периодам. Бизнес-смысл: выявление перегрузок конкретных сотрудников в конкретные периоды.
- «Документы и закрытие» — готовность документов проверок и наличие закрытия рекомендаций. Бизнес-смысл: контроль завершенности процесса от проверки до подтверждения результата.

## Экспорт аналитики

В боковой панели каждой вкладки можно выбрать формат экспорта и набор секций. Пользователь может включить все секции или очистить выбор. Экспорт не вызывает отдельный analytics API: он использует уже рассчитанные клиентские данные и текущий набор фильтров.

Текущие форматы:

- XLSX — структурированные листы по выбранным секциям.
- PDF / визуальный отчет — используется там, где поддержан соответствующий exporter.

## Ограничения

- Клиентская аналитика ограничена уже загруженными объемами `checks` и `recommendations`.
- Нет server-side агрегаций, drill-down API и сохраненных серверных отчетов.
- При росте данных может потребоваться backend analytics API с серверной фильтрацией, агрегациями и пагинацией.
- Наблюдения пока не участвуют в аналитике как отдельная сущность: во frontend есть демо-таблица наблюдений, но backend CRUD/API для наблюдений еще не реализован.
