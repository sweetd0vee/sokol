# Тестовое АЗ для импорта рекомендаций

Файл: `аз_тест_индикаторов.docx`

Мини-заключение по шаблону АЗ: титул, содержание, раздел I, наблюдения с **рамочками**.  
Подразделения — из справочника департаментов, ФИО — из справочника аудиторов (руководитель одной рекомендации — `Ковалев С.С.` из пользователей).

Индикаторы считаются от срока контроля и текущей даты (Москва):

- срок **позже сегодня** → серые песочные часы + серый колокольчик (`на контроле`)
- срок **сегодня или раньше** → красный треугольник + красный колокольчик (`не решено` / `срок нарушен`)
- вместо срока **«исполнено в ходе аудита»** → синяя звезда + зелёный колокольчик (`в срок`)
