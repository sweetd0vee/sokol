# Тестовое АЗ для импорта рекомендаций

Файл: `аз_тест_индикаторов.docx`

Это небольшой пример аудиторского заключения с **6 рекомендациями** и разными сроками контроля. Его можно загрузить в проверку кнопкой **«Загрузить из АЗ»**.

Индикаторы считаются от срока контроля и текущей даты (Москва):

- срок **позже сегодня** → серый колокольчик + серый колокольчик (`на контроле`)
- срок **сегодня или раньше** → жёлтые часы + жёлтый колокольчик (`в процессе`)

| № | Наблюдение | Срок контроля | Ожидаемые индикаторы на 28.09.2026 |
|---|------------|---------------|-------------------------------------|
| 3.1 | Несвоевременное обновление лимитов кредитования | 15.01.2025 | жёлтые часы + жёлтый колокольчик |
| 3.2 | Неполный регламент обработки инцидентов | 01.06.2026 | жёлтые часы + жёлтый колокольчик |
| 3.3 | Отсутствие сверки клиентских данных | 27.09.2026 | жёлтые часы + жёлтый колокольчик |
| 4.1 | Неактуальные матрицы доступа | 28.09.2026 | жёлтые часы + жёлтый колокольчик |
| 4.2 | Задержки закрытия периода | 15.10.2026 | серый колокольчик + серый колокольчик |
| 4.3 | Неполный комплект договорных шаблонов | 31.12.2027 | серый колокольчик + серый колокольчик |

Пересобрать файл:

```bash
py -3.12 sokol-backend/scripts/generate_az_indicator_sample.py
```
