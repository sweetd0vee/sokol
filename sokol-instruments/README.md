# sokol-instruments — legacy (Streamlit)

> **Не используйте для новой разработки.** Актуальный стек: [корневой README](../README.md) — React (`sokol-frontend`) + FastAPI (`sokol-backend`). Логика генерации DOCX перенесена в `sokol-backend/app/services/reports/`.

Это ранний **Streamlit**-прототип инструментов АЗ/ДЗ (порт по умолчанию **8502**). Сохранён для локального однофайлового запуска без Docker/Node.

## Когда имеет смысл

- Быстро проверить парсинг Раздела II на `.docx` без поднятия полного SOKOL.
- Сравнить поведение со старой версией алгоритма (код здесь может отставать от backend).

## Запуск (Windows)

1. Установите Python 3.12+ ([python.org](https://www.python.org/downloads/), **Add Python to PATH**).
2. Дважды щёлкните **`start.bat`** — установит зависимости и откроет браузер.

Если порт занят — в `start.bat` замените `8502` на другой (например `8503`).

**Не запускайте** `streamlit run app.py` из Anaconda — используйте `start.bat` и venv проекта.

## Возможности

- **АЗ:** парсинг Раздела II (с гиперссылками и без).
- **ДЗ:** докладная записка из АЗ с заполненным Разделом II; объекты аудита нормализуются по встроенному справочнику департаментов SOKOL (как в backend).
- Drag-and-drop `.docx` → скачивание результата (файлы на диск проекта не сохраняются).
