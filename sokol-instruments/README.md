# SOKOL: простой запуск

Инструкция для Windows.

## 1. Установите Python

Скачайте Python с сайта https://www.python.org/downloads/.

При установке обязательно поставьте галочку **Add Python to PATH**.

## 2. Запустите приложение

Откройте папку проекта и дважды нажмите на файл:

**start.bat**

Он сам установит все нужное и откроет приложение в браузере.

## 3. Что делать в приложении

1. На вкладке **АЗ** выберите действие:
   - **Парсинг Раздела II** — таблица без гиперссылок;
   - **Парсинг Раздела II (с гиперссылками)** — названия наблюдений в таблице ведут к тексту в документе.
2. На вкладке **ДЗ** можно сформировать докладную записку из АЗ с заполненным Разделом II.
3. Перетащите файл `.docx` в окно браузера и нажмите **Сгенерировать и скачать**.

Файлы не сохраняются в папку проекта. После генерации скачивание начнется автоматически.

## Если приложение не запускается

Если рабочий компьютер блокирует порт, откройте файл **start.bat** и замените `8502` на другой порт, например `8503` или `8510`.

Не запускайте командой `streamlit run app.py` из Anaconda. Используйте **start.bat**, чтобы приложение запускалось из окружения проекта.
