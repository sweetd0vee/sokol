## Что уже в порядке

- Слои FastAPI держатся контрактом: endpoint → service → CRUD. CRUD не коммитит и не тянет services (`tests/test_crud_layer_boundary.py`).
- Роль на каждом запросе читается из БД, не из JWT. Запись проверок, рекомендаций и вложений проходит `ensure_user_can_manage_*`.
- В prod старт падает на слабом JWT, demo-load и seed replace (`startup_validation.py`).
- Ошибки домена уходят клиенту как `{detail}` без traceback. Логи с request-id, в prod — JSON.
- Статусы рекомендаций и проверок, ключи, RBAC, парсер Раздела II и фильтры аналитики покрыты unittest (~43 файла). На фронте Vitest закрывает payload форм, матрицы, автостатус и экспортные хелперы.
- В UI есть error boundary на корне, на маршруте и на карточке графика. Пользовательский текст в React не собирается через `innerHTML`.

## Что блокирует прод

1. **Чтение не режется по владельцу.** Любой вошедший пользователь получает списки, карточки и все дашборды. Для одного департамента это может быть нормой. Для нескольких — нет.
2. **Нет Alembic.** Схема — `create_all` плюс идемпотентные SQL-патчи. Часть патчей не входит в bootstrap. Два окружения могут разъехаться без журнала версий.
3. **Секреты и пароли по умолчанию.** Пустой CORS → `*`. Docker включает demo, пока env не переопределён. Seed-пароли `admin` / `auditor`. Старые пароли без префикса PBKDF2 всё ещё принимаются как открытый текст. Минимальная длина нового пароля — 4. TTL JWT — 480 минут. Лимита на `/auth/login` нет. OpenAPI `/docs` включён всегда.
4. **Сессия в `localStorage`.** `utils/authSession.ts` хранит пользователя вместе с access token. XSS забирает сессию. HttpOnly cookie нет.
5. **Нагрузка на старте сессии.** Фронт тянет до 10 000 проверок и рекомендаций. Ночной пересчёт статусов грузит обе таблицы в память. Посещённые вкладки аналитики остаются смонтированными. Тяжёлые библиотеки экспорта (exceljs, docx, pdfmake, recharts) попадают в основной бандл: `React.lazy` нет, библиотек XLSX три.

## Чеклист перед включением

- [ ] `SOKOL_ENV=prod`, свой `SOKOL_JWT_SECRET`, явный `SOKOL_CORS_ORIGINS` (не пустой).
- [ ] `SOKOL_LOAD_DEMO_DATA=0`, `SOKOL_SEED_REPLACE` выключен, свои `SOKOL_ADMIN_PASSWORD` и `SOKOL_DEFAULT_USER_PASSWORD`.
- [ ] Пользователи перелогинены так, чтобы в БД остались только PBKDF2-хеши.
- [ ] Postgres и MinIO не торчат в интернет; `/docs` закрыт сетью, если Swagger не нужен снаружи.
- [ ] Бэкап Postgres и бакетов MinIO проверен восстановлением. См. [DATA_AND_DB.md](DATA_AND_DB.md), [STORAGE.md](STORAGE.md).
- [ ] Решение по чтению зафиксировано: «все свои» или отдельный ACL.

## Что не рефакторить без золотых тестов

Статусы (`recommendation_status.py`, `check_status.py`, `recommendationAutoStatus.ts`), SQL-агрегаты и русские литералы аналитики, `person_match`, ключи проверок и каскад кода аудитора, парсер и XML Раздела II, shape closure, section id экспорта и черновики конструктора.

Безопасная уборка, которая уже сделана в этом проходе: одно имя локального OOXML-тега в `reports/ooxml.py`, общий `EMPTY_CHECKS_SUMMARY`, удалён неиспользуемый алиас `CrudServiceError`.
